## Requirements

- Specify base64 transaction wire bytes, v0 wrap versus v1 payment/withdrawal,
  unsigned signature slots, signer ordering and unchanged-message signing.
- Specify standalone `{request_id, signature}` confirmation versus run batch
  confirmation by position. Explain response fields, failures and safe retries.
- Describe the reveal-risk flag on successful preparation, preflight and 409,
  including its amount-free payment references and acknowledgement gate.
- Cover reads (B3), activation (B5), apply-pending (B6) and CSV (B8), marking
  missing endpoints as proposals. Document the implemented auditor read/grants
  and their differences from the mock's paging, counterparty and invite model.
- Describe Supabase Auth verification, wallet association and route-specific
  authorization, including unauthenticated wrap and role-free owner run access.
- Document fixed error codes and their HTTP status, with the structured
  reveal-risk exception. No error may disclose an amount or request secret.
- Answer the issue's frontend questions where the code establishes the answer;
  retain account discovery, onboarding, idempotent run recovery and team
  decisions as explicit integration gaps.
